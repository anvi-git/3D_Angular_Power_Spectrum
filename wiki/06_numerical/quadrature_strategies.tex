\subsection{Quadrature Strategies for Cosmological Kernels}\label{subsec:num_quadrature}

This section details optimal quadrature strategies for the oscillatory and smooth integrals appearing in cosmology.

\subsubsection{Gauss-Legendre for smooth integrals}

For smooth integrands over finite intervals $[a,b]$:

\begin{equation}
\int_a^b f(x) dx \approx \sum_{i=1}^n w_i^{\text{GL}} f(x_i^{\text{GL}})
\end{equation}

**Advantages**:
- Exact for polynomials up to degree $2n-1$
- High order convergence for smooth $f$
- $n = 10$--20 usually sufficient

**Julia**: `using QuadGK; quadgk(f, a, b)`

\subsubsection{Adaptive quadrature for oscillatory integrals}

For integrals with Bessel functions $\int j_\ell(kx) g(x) dx$:

Use adaptive subdivision with automatic error estimation. QuadGK automatically detects oscillations and refines.

\textbf{Strategy}:
1. Start with coarse quadrature
2. Estimate error using Gauss-Kronrod pair
3. If error too large, subdivide interval and recurse
4. Continue until desired tolerance met

**Julia**: `quadgk(f, 0, Inf; rtol=1e-8, atol=1e-12)`

\subsubsection{Transformed integrals for unbounded domains}

For $\int_0^\infty f(x) dx$, use change of variables $x = \tan(u)$ or exponential map:

\begin{equation}
\int_0^\infty f(x) dx = \int_0^{\pi/2} f(\tan u) \sec^2 u \, du
\end{equation}

The Jacobian $\sec^2 u$ vanishes at endpoints, helping quadrature.

\subsubsection{Chebyshev nodes for fast evaluation}

If many evaluations needed (e.g., grid computation), use Chebyshev interpolation:
1. Evaluate $f$ on Chebyshev nodes $x_i = \cos\left(\frac{(2i-1)\pi}{2n}\right)$
2. Fit Chebyshev polynomial: $f(x) \approx \sum_{k} c_k T_k(x)$
3. Integrate analytically: $\int_{-1}^1 f(x) dx \approx \int_{-1}^1 \sum_k c_k T_k(x) dx$

**Advantage**: O(n) evaluation; reuse for many integrands.

See \cref{subsec:num_bessel} for specialized treatment of Bessel function integrals.
