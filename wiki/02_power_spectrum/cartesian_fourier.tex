\subsection{Cartesian Fourier Transform and Plane Waves}\label{subsec:ps_cartesian}

This subsection introduces the standard Cartesian Fourier decomposition of 3D fields, which serves as a reference point for all other decompositions.

\subsubsection{Field expansion in plane waves}

Any square-integrable scalar field $f(\mathbf{x})$ defined in 3D Euclidean space can be expanded as:

\begin{equation}
f(\mathbf{x}) = \frac{1}{(2\pi)^3} \int d^3\mathbf{k} \, \tilde{f}(\mathbf{k}) \, e^{i\mathbf{k} \cdot \mathbf{x}}
\end{equation}

The inverse transformation extracts the Fourier coefficients:

\begin{equation}
\tilde{f}(\mathbf{k}) = \int d^3\mathbf{x} \, f(\mathbf{x}) \, e^{-i\mathbf{k} \cdot \mathbf{x}}
\end{equation}

where $\mathbf{k}$ is the wave vector, related to wavelength by $\lambda = 2\pi / |\mathbf{k}|$.

\subsubsection{Isotropy: dependence on magnitude only}

For an isotropic field (same statistics in all directions), the Fourier coefficients depend only on $k = |\mathbf{k}|$, not on direction:

\begin{equation}
\tilde{f}(\mathbf{k}) = f(k) \cdot Y(\hat{\mathbf{k}})
\end{equation}

where $\hat{\mathbf{k}} = \mathbf{k}/k$ is the direction and $Y$ is an angular weight function (e.g., spherical harmonic).

\remark{
This isotropy is fundamental in cosmology: the universe looks the same in all directions (at least on large scales), so we expect all statistical quantities to be isotropic.
}
